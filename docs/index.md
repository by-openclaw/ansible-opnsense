# ansible-opnsense — Collection Documentation

> Ansible collection `by_systems.opnsense` for OPNsense firewall automation.
> Thin wrapper modules around [lib-opnsense](https://github.com/by-openclaw/lib-opnsense).
> Requires OPNsense >= 26.1.
